What is Git?

Git is a version control system which is used to track our project's progress over develop lifecycle we can track changes througout the project so that anything that should not happen we can track back to out previous check point... the checkpoint is previous commit that we have done.

What is Commit?

A commit is point that we tell Git to include this point and if in future i do some wrong thing i can track back to this point and manage my code. Before we make commit we add files to be commited this place is called staging area here Git knows that files that will be commited.

What is Branch and Branching in Git?

Branching is used when we want to make a new feature and we want that if it not worked as expected we can revert back to the main branch like tree has branch we can make branch and goes back to main branch it called merging where we merge our new branch to out main branch.

What is stashing?

Stashing in git is done when you have made mess in code, files and you urgently need to change something from previous like rename any file or make necessary chnage to code and much more things. stash temporary holds your mess and allow you to change previous thing by providing you clean working tree when you do nesessay change now you can clear your mess.

What is git Push?

Git push is used when we want to see commits and changes in our remote repository like github from our local machine. It pushes our code commits and changes we make in our local repository to a remote location.

What is git Pull?

Git pull is used when we make changes to our remote repo on Github and now we want to see those changes in our local repository on our local machine. eg. (we update README.md on github and now we want to see that in local repo). It pulls those changes we make in our remote repository to our local machine.
